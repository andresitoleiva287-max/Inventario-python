# Sistema de Inventario en Python

Sistema de gestión de inventario desarrollado con Python y MySQL.

## Funcionalidades
- Listar productos.
- Buscar productos por nombre.
- Registrar productos.
- Actualizar stock.
- Consultar productos con stock bajo.
- Modificar precios.

## Tecnologías
- Python
- MySQL
- mysql-connector-python
- python-dotenv

## Instalación
python -m pip install -r requirements.txt

## Ejecución
python inventario.py
